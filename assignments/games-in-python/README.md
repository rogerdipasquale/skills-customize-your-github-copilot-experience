
# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build a Python-based Hangman game that reinforces string manipulation, looping logic, and user interaction.

## 📝 Tasks

### 🛠️ Game Mechanics and Word Selection

#### Description
Create the main game loop and randomly select a secret word from a predefined list.

#### Requirements
Completed program should:

- Randomly select a word from a list of possible secret words
- Initialize and display the hidden word progress using underscores (_ _ _)
- Accept player letter guesses and update the displayed progress


### 🛠️ Guess Tracking and Game End

#### Description
Track incorrect guesses, manage remaining attempts, and display the final win or lose outcome.

#### Requirements
Completed program should:

- Track incorrect letter guesses separately from correct guesses
- Limit the number of wrong attempts and show remaining guesses
- End the game when the word is fully guessed or attempts run out
- Display a win message if the player guesses the word, or a lose message if not
